# If Something Happens

A mobile application concept for helping loved ones navigate an emergency or death: benefits, insurance, accounts, contacts, documents, personal wishes, and digital affairs.

The [Product Requirements Document](PRD.md) defines the first production release: scope, user journeys, functional requirements, access and permissions, benefits workflows, digital affairs, integration boundaries, and acceptance criteria. Implementation has not started.

Supporting [discovery and research documents](docs/README.md) preserve the founder's intent, map work following a death, record digital-account procedures, and link the supporting evidence.
